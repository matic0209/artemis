# 快速开始

## 环境准备
- Rust 工具链：推荐使用 `rustup` 安装最新 stable 版本
- 必要依赖：`pkg-config`、`openssl` 等原生库视系统需求安装
- 以太坊节点：支持 WebSocket 的全节点或服务商（Infura、Alchemy 等）
- 可选服务：Flashbots、RBuilder、Prometheus 抓取端

## 仓库初始化
```bash
# 克隆项目
git clone https://github.com/artemis-xyz/artemis.git
cd artemis

# 同步子模块（若有）
git submodule update --init --recursive

# 配置环境变量
touch .env
# 可参考 env.example 填写下列字段：
# WSS、OPENSEA_API_KEY、PRIVATE_KEY、ARB_CONTRACT_ADDRESS 等
```

## 构建与验证
```bash
rustup target add wasm32-unknown-unknown # 若需部署合约
cargo fmt --all --check
cargo clippy --workspace -- -D warnings
cargo check --workspace --all-targets
```

> 提示：当前仓库仍存在若干实验性模块，`cargo clippy` 可能需要以 `-A dead_code` 等参数放宽检查。

## 运行主程序
```bash
cargo run -p artemis -- \
  --wss wss://mainnet.infura.io/ws/v3/<PROJECT_ID> \
  --opensea_api_key <API_KEY> \
  --private_key <HEX_PRIVKEY> \
  --arb_contract_address <ADDRESS> \
  --bid_percentage 80
```

### 常用参数
- `--block_buffer_size`：Collector 内部缓冲区大小，默认 1024
- `--benchmark`：启用基准测试模式，跳过真实执行
- `--enable_rbuilder`：开启 RBuilder 扩展，需同时提供 `--rbuilder_url`

## 示例与脚本
- `examples/quick-start`：最小可运行案例，演示事件→策略→执行的主流程
- `examples/integration-demos/*`：完整 MEV Bot、Sandwich Bot 等场景
- `scripts/`：常用运维脚本（启动、监控、部署）

## 指标与监控
- 程序启动后默认在 `127.0.0.1:9000/metrics` 暴露 Prometheus 指标
- 建议结合 Grafana 或 Loki 打造统一监控面板

## 故障排查
- **无法连接节点**：确认 WebSocket URL、私钥格式与网络连通性
- **策略未产出**：查看 `tracing` 日志，确认 Collector 事件是否触达
- **交易执行失败**：复查 Gas、MEV 保护策略及 Flashbots 身份配置

更多进阶细节请参阅 `docs/架构设计.md` 与 `docs/开发工作流.md`。
