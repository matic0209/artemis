# 项目概览

## 背景与目标
Artemis 致力于为 MEV 研究者、量化团队与安全工程师提供统一的实验平台，用于：
- 快速验证套利、搬砖、抢跑/跟跑等策略可行性
- 分析 DeFi 协议在极端情况下的行为，评估攻击面
- 构建面向生产环境的自动化执行引擎，并具备实盘观测指标

## 典型使用场景
- **策略研发**：利用图论、符号执行与 REVM 复现筛选高收益机会
- **防御研究**：模拟 Sandwich 等攻击，制定保护脚本或监控规则
- **全链监控**：Collector 体系可扩展至多链节点，生成统一事件流
- **性能调优**：通过零拷贝处理、并发调度、批处理等优化手段压缩延迟

## 核心组件
- **Collectors**：负责从节点、API 或消息队列持续拉取数据，统一封装为事件
- **Engine**：将 Collector、Strategy、Executor 串联，负责事件调度与生命周期管理
- **Strategies**：根据事件生成套利/防御动作，支持多策略并行
- **Executors**：对动作进行签名、打包与发送，支持 Flashbots / Mempool / 自定义执行渠道
- **工具链**：Prometheus 指标、基准测试模式、配置模板、示例工程等

## 数据流简述
1. Collector 持续监听区块、订单或内存池，生成标准化事件
2. Engine 将事件派发给符合条件的 Strategy
3. Strategy 结合内部状态、图论/符号执行分析，输出 Action
4. Executor 将 Action 转换为链上交易或其他操作，结果回流到 Engine
5. 监控线程通过指标端点暴露实时运行状态
